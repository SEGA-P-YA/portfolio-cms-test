# portfolio-cms-test

イラストポートフォリオサイトの **Pages CMS 認証・編集機能テスト用** リポジトリです。
本番サイトではありません。ダミーデータのみを使用します。

## 構成

- `.pages.yml` — Pages CMS の設定（作品コレクション、メディア保存先）
- `works/` — 作品データ（Markdown + フロントマター）。CMSの「作品」コレクションから編集します
- `images/` — 作品画像の保存先。CMSからアップロードした画像はここに入ります
- `index.html` — テスト用の最小ページ

## テスト手順（STEP 2〜4）

1. 管理者（SEGA）が app.pagescms.org に GitHub アカウントでログインし、このリポジトリを開く
2. 管理者が家族をメールアドレスで招待する
3. 家族がメール内のリンク（マジックリンク）から、GitHub アカウントなしでログインできるか確認する
4. 家族が作品の追加・編集・削除、画像アップロード、公開／非公開の切り替え、詳細ページ設定を行えるか確認する
5. 家族から CMS の設定や他の編集者の管理が変更できないことを確認する
6. スマートフォンからログイン・編集できるか確認する

## 作品の項目

タイトル、作品画像、サムネイル、カテゴリー（FAN ART / COMMISSION / WORKS / ORIGINAL）、
制作年、説明、表示順、公開／非公開、メインビジュアル設定、詳細ページの有無と詳細内容。

詳細ページを作らない作品では、詳細ページ用の項目は入力不要です。
